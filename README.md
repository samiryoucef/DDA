# Du Développement au Déploiement d'Application

Ce dépôt contient les exemples de code et les travaux pratiques réalisés dans le cadre du cours DDA.

Vous y trouverez les programmes étudiés en cours ainsi que les différentes manipulations effectuées pendant les séances de TP. L'objectif est de pouvoir retrouver facilement les exemples, les consulter et les reprendre pour les exercices.

## Contenu du dépôt

### RMI (Java)

Le répertoire `RMI` contient un premier exemple de communication entre un serveur et un client Java à l'aide de Java RMI.

Cet exemple permet de comprendre le principe des appels de méthodes à distance et de voir comment un client peut communiquer avec un serveur.

### SOAP (Python / PHP)

Le répertoire `SOAP` contient un exemple de service Web SOAP développé en Python, ainsi qu'un client PHP permettant de l'utiliser.

Ce TP permet notamment de manipuler un service Web et de voir comment deux applications écrites dans des langages différents peuvent communiquer.

## Organisation

- `RMI/` : exemple de serveur et de client Java RMI.
- `SOAP/` : service Web SOAP en Python et client PHP.

D'autres exemples et travaux pratiques seront ajoutés au fur et à mesure de l'avancement du cours.

## Utilisation du dépôt

Les codes présents dans ce dépôt servent de support aux séances de cours et de TP. Il est conseillé de les récupérer, de les exécuter et de les tester afin de mieux comprendre leur fonctionnement.

Lorsque des modifications sont apportées en séance, vous pouvez également vous appuyer sur ces exemples pour reprendre le travail et poursuivre les exercices.

Bon travail.
